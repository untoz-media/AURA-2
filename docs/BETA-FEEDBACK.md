# AURA-2 Testing Feedback

Use the repository issue forms for normal preview feedback.

Before reporting a bug:

1. reproduce it once more if safe
2. restart AURA and note whether it persists
3. open **Settings → Beta & Diagnostics**
4. run the self-check
5. export the diagnostics snapshot
6. review the file before sharing anything

The diagnostics snapshot is explicitly allowlisted and is intended to contain technical state only. It must not contain prompts, model responses, memory contents, screenshots, transcripts, credentials or arbitrary file contents.

For security vulnerabilities, use a private GitHub Security Advisory instead of a public issue.

Release-blocking preview issues include install/startup failures, permission bypasses, unintended Sensitive/Destructive execution, data loss, background Automation boundary escapes, Agent execution outside the validated plan, unrecoverable crashes and inability to pause/cancel active work safely.
